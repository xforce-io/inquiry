# 名词表

| 规范名 | 一句话定义 | 禁止别称 |
|---|---|---|
| Inquiry | 基于 TaskLoop、以证据推进判断的持续研究应用。 | — |
| TaskLoop | 为 Inquiry 提供规划、路由、执行、评价与重规划能力的通用任务运行时。 | — |
| Skill | 以版本化包表达能力方法、输入输出约束与配套资源的资产。 | — |
| Schema | 定义领域数据和交换契约的结构规范。 | — |
| Agent Harness | 承担模型推理、执行会话和工具调用循环的第三方执行框架。 | — |
| 研究问题 | 用户提交且含范围、约束和完成标准的研究对象。 | — |
| 资料 | 有来源身份、获取处置和保存内容版本的研究输入。 | — |
| 证据 | 在特定保存内容版本定位、用于支持或反驳判断的原文及引用关系。 | — |
| 判断 | 关联支持、反驳证据与限制的解释或主张。 | — |
| 报告 | 汇集结论、可回溯引用、限制及未决项的交付物。 | — |
| 深度文章 | 围绕复杂研究问题形成完整解释与论证、跨源综合并明确反证及边界的报告。 | — |
| 质量评价 | 按固定研究要求检查确切报告版本并逐项记录结论与依据的活动。 | — |
| 验收规则 | 运行前固定、定义目标达标条件及所需证据的版本化规则。 | — |
| 研究限制 | 现有资料不能消除、必须在结论中披露的未知与适用边界。 | — |
