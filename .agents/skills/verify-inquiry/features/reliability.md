# 可靠查看、补充和停止（S3）

入口：详情页、创建页；只使用公开五操作。确定性HTTP集成测试与真实模型/浏览器分开记账。

1. 同一Skill创建A/B，输入/计划/资料独立；A停止不误停B，同研究路径不得读另一研究Artifact。
2. 刷新详情回到公开状态/已接纳内容；查询错误保留上次内容，恢复后重试，不创建新实例。
3. 同键相同输入重试同一ExecutionId，改输入复用键拒绝；响应丢失不生成另一研究。
4. 等待资料显示缺口和表单；补URL携带当前revision，冲突保留内容、刷新核对；到期明确部分结果，不能叫报告就绪。
5. 停止先显示取消中，确认后才已停止；已有产物保留。真实运行的取消必须实际执行；确定性替身不能证明Harness停止。

涵盖刷新、同键重试、补网址、冲突/到期、停止5类边界。网络断开用受控本次服务停止/恢复，禁止全局清用户网络/浏览器数据。到期使用生产业务定义缩短等待的明确fixture，记录该环境差异，不能把fixture时间冒充真实24小时等待。
