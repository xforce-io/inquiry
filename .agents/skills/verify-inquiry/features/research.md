# 研究闭环（S1）

入口：创建页。正式实验先完成 quality.md 的事前登记。

1. 填共同问题、可选来源/范围，看清资源限制后开始。记录受理后的研究地址，未受理错误保留输入。
2. 从公开快照与页面确认 scope/discover/capture/catalogue/analyze/report 六阶段真实执行。中间展示仅来自已接纳产物，检索结果不得叫已留存来源。
3. 报告就绪后阅读结论、限制与未知；点至少一条编号引用，面板定位保存版本、段落和高亮短引文。
4. 关闭面板继续原位置阅读，刷新后报告及来源仍可读。保存真实研究ID、阶段产物、对应版本摘要、实际工具事实和截图。

失败判定：没有真实报告、少阶段、来源用当前网页代替历史、断链、错误被叫成功。仅静态 fixture 或编译通过一律不算本项pass。与 sources.md / web.md 共用同候选真实证据。

## 方法0.3.5预算修复复验（S1.B1）

用户明确要求的Vertex同题功能复验不等于第三次质量实验。先冻结原prompt字节、候选与原失败证据，新研究新目录。核对六阶段真实执行、80次分析预算及最终报告/引用；未完成如实FAIL，不改问题反复生成。
